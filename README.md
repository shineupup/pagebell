# 翻页提醒器 · Pagebell

双声提示的桌面翻页 / 计时提醒小工具。轻触即响，贴边常驻，不抢焦点——翻书、朗读、练琴、网课，需要"到点换一页"时，它替你记着。

## 特性

- **双声提示**：滴 / 铃 / 木 / 琴 / 风铃五种音色，频率、音量、声数可调，轻点即响。
- **迷你贴边**：一键收成小卡片，拖到屏幕任意边角常驻；拖动条就在卡片顶上。
- **沉浸隐藏**：静止数秒后自动淡出，鼠标靠近即回；透明度可调。
- **桌面版（Electron）**：网页套一层透明无边框壳，免安装也能跑。
- **安装包**：中文向导、**可选安装目录**、自带卸载器，出现在"应用和功能"里。
- **应用图标**：圆角玻璃质感的书本 + 铃铛（256×256 全尺寸内置）。

## 下载

安装包在 **GitHub Releases** 页：

👉 `https://github.com/<你的用户名>/pagebell/releases`

（别人电脑上首次运行若弹 SmartScreen，点"更多信息 → 仍要运行"即可，安装包未做代码签名。）

## 本地运行 / 打包

> 桌面版需要一份 Electron 运行时（约 230MB），本地打包时才用，不进仓库。

| 想做的事 | 怎么弄 |
|---|---|
| 不打包先看效果 | 双击 `预览.bat`（用本机已有的 Electron 直接拉起窗口） |
| 重新出安装包 | 双击 `build.bat`，产物在 `安装包\翻页提醒器-1.0.0-安装包.exe` |

## 目录结构

```
pagebell-web/
├─ index.html        网页主界面
├─ assets/           样式与脚本（style.css / app.js）
├─ desktop/          Electron 壳（main.js / preload.js / icon.ico）
├─ tools/            图标生成、NSIS 调试等内部脚本
├─ build.py          一键打包：同步界面 → 注入图标 → NSIS 编译
├─ build.bat         双击即跑 build.py
├─ 预览.bat          免安装预览
├─ dist/             （不入库）Electron 运行时，本地打包用
└─ 安装包/            （不入库）编译产物，请发到 Releases
```

## 技术栈

网页（HTML / CSS / JS，玻璃质感 UI）+ Electron 桌面壳；NSIS 手写安装向导。
